# Project Guidelines

## Code Style

- No comments in code unless absolutely necessary for complex logic
- Prefer self-documenting code with clear naming

## Tech Stack

- TanStack Start (full-stack React framework)
- TanStack Router + Query
- Drizzle ORM with PostgreSQL
- Tailwind CSS v4
- Zod for validation

## Project Structure

- `src/server/functions/` - Server functions (createServerFn)
- `src/hooks/` - React hooks including TanStack Query wrappers
- `src/lib/api/` - External API client (axios)
- `src/db/` - Database schema and connection
